# 末端执行器能力契约

## 当前实现

当前可复现运行时只实现 Franka Panda 平行夹爪（`parallel_jaw`）。能力门禁
会在构建 Genesis 场景之前执行。标记为 `suction_required` 或
`cradle_required` 的 profile 仍然是目录中的评测边界，在当前闭环运行时会被
明确拒绝。

这是有意设置的真实性和安全边界。一个“大型扁平包裹”的目录描述，不等于
平行夹爪已经能够可靠地操作它。

## 扩展契约

只有同时完成以下内容，才能启用新的末端执行器：

1. 提供有版本记录的 Genesis 资产和碰撞几何。
2. 提供使用相同观测/动作契约的控制适配器。
3. 提供确定性的 reset 和 release 流程。
4. 提供适合该工具的接触力与失败指标。
5. 提供独立的训练集、验证集和最终留出集回合。
6. 提供可复现的 ROCm 冒烟测试和闭环报告。

完成后，应通过显式运行时配置把新的 handling class 加入能力注册表，不能
修改默认平行夹爪结果。

## 对当前评分的影响

当前项目可以对平行夹爪处理的盒状和圆柱 profile 做有证据支持的声明。吸盘
或 cradle 支持必须等扩展契约完成后再声称。这样能保持机器人能力评分的可信
度，也能防止不支持的 profile 污染模型比较。
