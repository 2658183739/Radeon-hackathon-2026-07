# Genesis Panda Finger Control-Input Replay Results

## Outcome

The preregistered control-input replay recovered the missing mechanism needed
to reproduce the mass-aware source failure in a fresh scene, but it did not
produce a valid cross-model inertia comparison.

| Condition | First safety event | Peak force | Maximum penetration | Result |
|---|---|---:|---:|---|
| Recorded mass-aware source | `203/4` high-rate, frame 204 abort | 162.186 N | 115.546 mm | known failure repeated |
| Stock inertia replay | `198/1` | 157.787 N | 115.544 mm | invalid reference |
| Mass-aware replay | `203/4` | 162.186 N | 115.546 mm | source failure reproduced |

The machine comparison conclusion is `invalid_reference` because both replay
conditions crossed the unchanged 35 N and 1 mm boundaries. It is therefore
not valid to attribute the paired replay difference to adapter inertia.

## What the new capture established

All 64 source events used the same nine-DOF control-mode signature: seven arm
DOFs in position mode and two finger DOFs in force mode. Finger force targets
remained fixed, while the arm position target changed only at the 30 Hz frame
boundaries `197/0` through `203/0`. The prior open-loop force replay discarded
these moving PD targets, which explains why it could not reproduce the branch.

Starting from source state `196/0`, the mass-aware replay reproduced the same
first high-rate force event at `203/4`, the same reported peak force, and the
same maximum penetration to serialized precision. Across 60 aligned events,
robot qpos differed by `0.0`; the largest velocity difference was
`3.8147e-6`, the largest force difference was `3.2425e-5 N`, and the largest
penetration difference was `1.8626e-9 m`. These are reported directly rather
than being converted into a post-hoc acceptance threshold.

## Interpretation boundary

Raw mode-specific control inputs are sufficient to reproduce the observed
mass-aware failure event in a fresh scene. A contact-solver warm start is not
required for that reproduction. However, initializing the stock model from a
state generated by the mass-aware model is not a safe counterfactual: the stock
scene failed earlier at `198/1`. This experiment neither proves nor disproves
that added inertia caused the original full-trajectory regression.

The 30 mm mass-aware adapter remains rejected and default off. No mode, target,
gain, density, extension, solver option, start frame, candidate, episode, or
threshold was scanned. No new episode or holdout was opened. The adapter branch
is closed for this observed episode; the main project should return to the
stock-hand geometry-planning and candidate-ranking baseline unless a separate
full-trajectory physical adapter design is preregistered.
