# Genesis Panda 指爪控制输入回放协议

## 触发条件

精确广义状态加开环力回放没有重现质量感知适配器在闭环中的
162.186 N 接触冲击。两个新场景都以实测零误差恢复机器人和包裹的
`qpos/qvel`；原装惯量场景峰值为 10.586 N，质量感知场景为 7.316 N，
均未越过保持不变的 35 N 或 1 mm 安全边界。

本协议检验下一项有界假设：仅有广义状态仍不充分，因为生产场景保留
了位置控制模式和 PD 目标，而事后控制力无法唯一还原这些输入。

## 冻结流程

### 阶段一：一次只读来源捕获

只重跑已经观察过的质量感知条件
`medium_carton / 4120001 / canonical-long-+0.000-up-0.045`。保持生产控制器、
候选位姿、35 N 力中止、240 Hz 物理频率和第 196--204 帧遥测窗口不变。
除已有状态外，在每个物理子步后记录 Genesis 原始九自由度 `ctrl_mode`、
`ctrl_pos`、`ctrl_vel` 和 `ctrl_force` 数组。

只有再次选中同一候选并重现已知安全故障时，来源捕获才有效。这些字段
必须只读，不得改变排序、控制、物理或停止行为。

### 阶段二：成对精确模式回放

分别在一个原装惯量新场景和一个合并惯量新场景中恢复事件 `196/0` 的
广义状态。为生成后续每个来源事件，按照该事件记录的控制模式，通过
Genesis 对应的公开位置、速度或力控制接口写入原始目标，然后只推进一个
240 Hz 物理步。回放中不得运行专家状态机、规划器、IK、相机或学习策略。

状态重建误差不得超过 `1e-6`。首次出现超过 35 N 的接触或不小于 1 mm
的穿透时停止。每个条件只运行一个场景，且只比较一次。

## 预注册解释

- 仅质量感知条件达到安全边界：缺失机制可由原始控制模式/目标和广义
  状态共同捕获。
- 两者均未达到边界但出现已注册轨迹差异：保留为有界控制/接触敏感性。
- 两者均无实质差异：位置目标/模式仍不充分，后续新协议才可检查 Genesis
  支持的完整求解器状态或暖启动状态。
- 原装惯量条件达到安全边界：成对归因无效。

禁止扫描来源帧、控制模式、目标、增益、物理选项、适配器密度/长度、力
阈值、候选位姿、episode 或 holdout 数据。
