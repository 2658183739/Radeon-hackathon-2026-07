# Sim-to-Real Status

**Status: pending; no Sim-to-Real claim.**

All reported results in this submission are generated in Genesis simulation. The 8/10 figure comes from a deterministic scripted expert agent that reads privileged simulator state; it is not VLA evidence. Future real-world validation, real-robot video, and a Sim-to-Real benchmark protocol are all **pending**.
