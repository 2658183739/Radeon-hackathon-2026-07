# 论文级几何方法评测协议

## 状态与边界

本文在执行新 episode 之前冻结下一轮评测，记录可观察证据、假设、备选方案、决策和停止
条件。它不是隐藏逐字思维链的转录。

当前几何感知规划器在配对的 `large_narrow_carton` 开发集上，把单张 Radeon 的成功数从
5/20 提高到 15/20，把力中止从 8/20 降到 4/20。`7000000`--`7000019` 已经影响过实现
选择，因此不能再当作未见确认性证据。

## 本轮筛选问题

碰撞检查复位和几何感知抓取规划，能否在均衡的可支持包裹 profile 上提高表现，同时不掩盖
简单盒体或圆筒的回归？

冻结协议为 `configs/campaign_geometry_screen_v1.toml`，包含 12 个平行夹爪可处理的训练
profile、每个 profile 5 个全新确定性 episode，以及三组严格配对对照：

1. `historical-controller`：历史复位与历史抓取控制；
2. `collision-checked-reset`：只开启碰撞检查复位；
3. `geometry-aware-planner`：碰撞检查复位加完整几何规划器。

每组使用同一批 60 个随机样本，总计 180 个闭环 episode。局部编号
`100000`--`100004` 只用于探索性筛选；`200000`--`200039` 单独保留，在最终方法和
确认性协议冻结之前不得查看。

需要吸盘或托架的 evaluation-only profile 不进入本轮。它们属于末端执行器能力边界，不能
错误地算成平行夹爪任务失败。

## 固定约束

- 只暴露一张 AMD Radeon，通过 ROCm 和 PyTorch `cuda:0` 运行；
- 固定 Genesis 物理、目录哈希、seed 42 和 30 Hz 控制频率；
- 三组全部保持 35 N 接触力硬中止，不得放宽；
- 统计前必须核对完整随机样本和 episode ID 完全一致；
- 查看筛选 episode 后再改参数的结果，不得包装成预注册结论；
- Genesis 清理阶段若返回 139，只有 runner 验证全部冻结 episode 与 profile 完整后才接受产物。

## 指标与统计

主要筛选指标为闭环任务成功。安全指标为力中止与掉落。次要指标包括最大接触力、仿真回合
时长、每小时成功件数、推理延迟和抓取规划耗时。

`scripts/analyze_campaign_results.py` 生成的报告包含：

- 计数、比例和 Wilson 95% 区间；
- 对配对成功、力中止、掉落执行双侧精确 McNemar 检验；
- 对接触力和时长报告“候选减基线”的配对均值、确定性 Bootstrap 95% 区间与符号翻转检验；
- 逐 profile 分层和 profile 宏平均，避免大 profile 掩盖圆筒回归；
- 规划尝试次数、同步总耗时和单次规划耗时。

每个 profile 只有 5 回合，所以本轮是淘汰筛选，不是可靠性声明。原始 p 值只用于诊断，
不能从本轮做未经多重比较校正的确认性结论。

## 筛选后的决策门禁

相对碰撞检查复位组，完整几何方法只有同时满足以下条件才进入下一阶段：

- 总成功数不降低；
- 力中止和掉落不增加；
- 任一支持 profile 的配对成功回归不超过 1/5；
- 规划器生效时，必须存在完整规划遥测；
- 规划器不生效的低盒与圆筒应保持配对行为；若有差异，必须归因并复现。

出现有效信号的 profile 再从保留命名空间取 20--40 回合做确认性评测。主要确认性对照是
“完整几何规划”对“碰撞检查复位”，成功率为主指标，力中止和掉落为安全共同指标。若新增
多个假设，必须在运行前声明检验族并采用 Holm 校正。

## 计划消融

筛选出真正相关的 profile 后，每次只关闭一个组件：

- 去掉碰撞过滤；
- 去掉可操作度排序；
- 去掉对称腕姿候选；
- 去掉 retry 重规划；
- 去掉高盒 2.5 mm 两级接近；
- 仅作诊断：开启 swept waypoint 碰撞检查。

最后一项不作为默认候选，因为此前实测没有拒绝任何挑战 waypoint，却每回合增加最多
7.76 秒开销。

## 模型与平台路线

当前主方法继续采用确定性几何规划与安全控制。这不是放弃学习，而是在训练前先建立可靠专家、
可解释安全层和可量化基线。随后按 ACT RGB、ACT RGB-D、轻量 Diffusion RGB-D、小型 VLA
高层任务条件的顺序推进，所有学习策略仍受同一个 35 N 监督器约束。

主要文献锚点已通过学术接口检索并记录在 `RESEARCH_AND_MODEL_MATRIX_CN.md`：ACT（RSS
2023，DOI `10.15607/RSS.2023.XIX.016`）、Diffusion Policy（RSS 2023，DOI
`10.15607/RSS.2023.XIX.026`）、DP3（RSS 2024，DOI
`10.15607/RSS.2024.XX.067`）、OpenVLA（arXiv `2406.09246`）和 Octo（RSS 2024，DOI
`10.15607/RSS.2024.XX.090`）。当前 GPU 碰撞感知规划方向也会对照 cuRobo（arXiv
`2310.17274`），但实现不依赖 CUDA 专用代码。

## 复现

在 Radeon 实例执行：

```bash
cd /workspace/parcel-sorter-opt-v1
bash scripts/run_geometry_screen_campaign_rocm.sh
```

runner 会校验 campaign 指纹、拒绝覆盖已有输出、在单卡上顺序运行三组、验证完整 summary，
并生成压缩证据、失败归因、配对比较、论文统计 JSON 和 SHA-256 清单。
