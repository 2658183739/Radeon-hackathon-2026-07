# Radeon 几何感知抓取规划

本文记录可观察的工程证据、假设、实现选择、实验和决策，是可审计的开发记录，不是模型内部
逐字思维过程。

## 结果

在单张 AMD Radeon `gfx1100` 与 ROCm 7.2 上，固定 20 回合
`large_narrow_carton` 对照从 5/20 成功提升到 15/20。候选恢复 10 个基线失败、没有造成
成功回归、保持 0 掉落；成功吞吐从每小时 98.25 件提升到 359.36 件。力中止从 8/20 降到
4/20，最大力从 111.30 N 降到 46.99 N。

候选仍属于实验能力。它没有通过预注册的至少 18/20 成功和最多 1/20 力中止门禁，因此
`geometry_aware_grasp_planning_enabled` 继续默认关闭。

## 问题与因果边界

Radeon link 级诊断证明，大纸箱经常在 30 Hz 控制器来得及反应前，就与历史 reset 姿态相交。
碰撞检查复位把困难集从 1/20 提升到 5/20，但剩余高纸箱仍会停在名义抓取上方或产生危险接触。
扩大“已到预抓取”容差只改变状态机时序，不能创造可行位姿，因此已被拒绝。下一项干预必须修改
抓取几何，而不是放宽完成语义或 35 N 安全边界。

## 已实现流程

1. 仅对高度达到 `105 mm` 手掌净空加 `20 mm` 最小侧面重叠，即至少 `125 mm` 的刚体盒启用
   规划。较低盒体完全保留历史控制、稳定等待和运动限制。
2. 候选包含长轴中心和最多 `+/-50 mm` 偏移、`0/20/40 mm` 与几何上限的竖直偏移，以及
   canonical 和等效的 `pi` 腕姿。
3. 每个位姿分别使用当前关节、历史 reset、无碰撞 reset 三种初值求解。IK/FK 误差、有限值、
   状态恢复和非夹指碰撞作为硬门禁。
4. 可行解优先中心、较低侧面接触，再比较关节距离、Jacobian 最小奇异值和非夹指净空。阈值内
   微米级 IK 噪声只算通过，不参与排序。
5. 选中的 XYZ 与四元数由接近、到位判定、闭合和抬升共享。重试会清空延迟动作并重新规划，
   不复用包裹移动前的旧位姿。
6. 规划抓取需要连续 5 帧双指接触；规划放置的最终下降限制为每控制步 5 mm。
7. 最终抓取接近采用两级几何步长：`125--160 mm` 使用 5 mm，`>=160 mm` 使用 2.5 mm。
   `160 mm` 来自 `105 mm` 手掌净空加 `55 mm` 最大竖直候选偏移。

## swept 碰撞门禁的负结果

实验门禁按最大单关节 `0.025 rad` 插值每段命令，并逐点检查非夹指碰撞。它保留了 4 个已知
恢复样例，却在 6 个力挑战中一次也没有拒绝 waypoint；这些回合仍在 `37.21--50.66 N` 中止，
门禁还额外增加每回合 `1.66--7.76 s` 同步检查。该功能只通过
`--grasp-planning-waypoint-gate` 显式启用，默认关闭，也不属于 v2 正式结果。

## 步长实验

限定作用域后的 5 mm 候选保住旧回归哨兵 `7000005`，并恢复 6 个力挑战中的 4 个；但
`7000008` 达到 115.11 N，`7000016` 达到 42.78 N。全局 2.5 mm 修复这两个回合，却使
中等高度的 `7000001/2` 回归。接触动力学的非单调结果排除了单一全局速度标量。

最终两级策略在没有 CLI 覆盖的情况下重新执行 4 个交叉哨兵。`7000001/2` 自动选择 5 mm，
以 31.38/21.42 N 成功；`7000008/16` 自动选择 2.5 mm，以 8.21/31.23 N 成功。通过后才
启动固定 20+20 对照。

## 正式协议与结果

两组固定相同 `large_narrow_carton`、seed、`7000000--7000019`、碰撞检查复位、物理、控制器、
35 N 硬中止、Radeon 设备与 ROCm 运行时。唯一允许的配置差异是
`task.geometry_aware_grasp_planning_enabled`。

| 指标 | 复位基线 | 几何规划器 | 变化 |
| --- | ---: | ---: | ---: |
| 成功 | 5/20（25%） | 15/20（75%） | +50 个百分点 |
| 力中止 | 8/20（40%） | 4/20（20%） | -20 个百分点 |
| 掉落 | 0/20 | 0/20 | 不变 |
| 成功吞吐 | 98.25/h | 359.36/h | 3.66 倍 |
| 最大力 | 111.30 N | 46.99 N | -64.31 N |

候选成功率的 Wilson 95% 区间为 53.13%--88.81%。这组小规模困难集不能写成生产可靠性。

## 剩余失败与下一步

`7000006/15/19` 仍在接近阶段力中止；`7000014` 在一次重试后的抬升阶段中止；`7000017`
到达预抓取后因丢失抓取而超时。下一步应研究低盒接触预测、无碰撞重试撤退和抬升保持，不能提高
35 N 上限，也不应继续对同一个困难集拟合高度阈值。

新候选达到至少 18/20 成功、最多 1/20 力中止后，再扩展到留出的盒体、扁平件和圆筒分层，
之后才能恢复均衡 RGB-D 采集和学习策略排名。
