## 已通过的验证

- 配置范围和频率约束
- 状态机成功、重试、抬升和安全中止路径
- 专家末端动作限幅和夹爪语义
- 随机化可复现性与范围检查
- nominal/in-domain/unseen 条件生成
- JSONL 轨迹与 manifest 格式
- 成功率、恢复率、掉落率、吞吐和 P95 延迟统计
- 完整闭环的模拟接口测试

以上逻辑测试已经由 Genesis 真实接触动力学和 Radeon/ROCm 实跑补充验证。

## 已达到的 GPU 验收门槛

确定性专家至少需要满足：

- 固定场景连续成功完成抓取、抬升和放置
- 左右格口均可执行
- 人为制造一次失败后能自动重试
- 接触力不超过配置上限
- MP4、轨迹和 summary 文件同步生成
- 运行报告中 `torch.version.hip` 非空且只暴露一张 Radeon

这些门槛均已达到。后续仍需把确定性专家和学习策略分开报告，不能用专家真值能力代替视觉策略成绩。

## 明确保留到下一阶段的内容

1. 降低最终接近阶段速度，优先消除接触力安全中止。
2. 重采困难包裹数据，并比较关闭强图像增强的 ACT 训练。
3. 增加深度融合、腕部 RGB 相机、遮挡和光照变化实验。
4. 可选的文本指令或轻量 VLA 对比，不替代当前可复现基线。
5. 为正式数据和权重生成 SHA-256 并上传附件。
6. 补齐团队信息、演示视频和最终比赛 PR。
