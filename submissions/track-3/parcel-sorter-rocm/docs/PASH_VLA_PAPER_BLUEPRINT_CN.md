# PASH-VLA 论文蓝图（基于现有证据，不扩展测试范围）

## 建议题目

**PASH-VLA：面向单 Radeon 移动双臂快递搬运的负载感知安全残差视觉语言动作方法**

英文题目：**PASH-VLA: Payload-Aware Safety-Harness Vision-Language-Action Control for
Single-Radeon Mobile Bimanual Parcel Handling**

## 摘要草稿

移动双臂快递搬运同时包含视觉语言决策、长时域移动、接触丰富操作和严格安全约束，直接执行
VLA 的绝对动作容易产生越界、接触冲击或任务超时。本文提出 PASH-VLA，一种运行于单张 AMD
Radeon GPU 与 ROCm 的负载感知安全残差 VLA。SmolVLA 在 3 Hz 生成 19 维底盘/双臂动作建议，
240 Hz 确定性专家提供名义动作；Harness 在五档残差候选中执行速度、进度、IK、工具互锁和
35 N 接触门控。本文进一步引入短时接触力记忆，对持续高载荷和快速上升趋势动态收紧学习策略
占比，并用截止时间存活门保证长件运输可完成。失败轨迹通过隔离的桥接课程进入近线再训练，
候选只有通过冻结任务、安全、实际执行、ROCm 来源和 Wilson 非劣性门才可晋级。系统使用三杯
柔顺吸盘和实体 V 型托架完成移动双臂负载分担。保留的 SmolVLA v2 在四类参数随机快递的冻结
100 回合中达到 96/100 且无 35 N 越界；失败驱动 v3 为 91/100 并被自动拒绝。在一个 1.44 m
超长箱开发案例中，PASH-VLA 完成 8.52 cm 抬升、30 cm 运输与 2.11 cm 误差放置，零断吸，
Force-Memory 在 68 次推理中 11 次收紧残差、2 次完全回退。结果表明，受控策略贡献和可拒绝的
自我改进比无条件扩大模型更适合单 GPU 接触搬运。超长箱结果仅为机理证据，不构成泛化结论。

## 研究问题

- **RQ1：**有界残差 Harness 是否比原始 VLA 或纯数值限幅更符合执行器动作包络？
- **RQ2：**接触力短时记忆能否在不修改基础权重和硬安全线的情况下抑制高风险 VLA 动作？
- **RQ3：**失败驱动再训练加冻结晋级门能否实现“可改进，也可拒绝退化”的近线自进化？
- **RQ4：**三吸盘/V 型托架和负载感知截止门能否扩展到单夹爪范围外的超长刚性快递？

## 方法形式化

令专家动作为 `a_e`，VLA 动作为 `a_v`，有界残差为：

```text
r = Clip(a_v - a_e; residual limits)
a(alpha) = a_e + alpha * r
alpha in {0, 0.25, 0.50, 0.75, 1.0}
```

候选必须同时满足有限值、底盘速度、笛卡尔步长、专家方向进度、工具阶段互锁、IK 和 35 N
硬门。没有安全学习候选时使用 `alpha=0` 的专家；达到硬力门时停止运动并进入安全响应。

最近 `W=6` 次接触力为 `F[t-W+1:t]`。Force-Memory 风险定义为：

```text
r_load = max(0, (max(F) - F_soft) / (F_limit - F_soft))
r_rise = max(0, (F_t - min(F) - d) / (F_rise - d))
risk = min(1, max(r_load, r_rise))
alpha <= 1 - risk
```

当前固定值为 `F_soft=20 N`、`F_limit=35 N`、上升死区 `d=2 N`、完全回退上升量
`F_rise=8 N`。这些值属于开发方法参数；PASH-v25 不据此声明统计优越性。

运输截止时间门为：

```text
if remaining_distance > remaining_time * expert_forward_speed * capacity:
    latch expert control for the rest of transport
```

协同件容量系数 `0.60` 来自独立专家 v20 的实际位移与理论速度上界之比，不通过 v24/v25
结果反向调成功门限。

## 三项主要贡献

1. **PASH 残差决策层：**把 VLA 提议、专家进度、接触力时间记忆和任务截止时间统一到可审计
   的候选选择问题中，而不是让 VLA 直接接管力矩或工具。
2. **可拒绝的近线自我改进：**失败回放、桥接课程、Radeon 再训练、冻结评估和 Wilson 晋级
   相互隔离；v3 被拒绝是方法正确工作的负证据。
3. **负载感知移动双臂形态：**三杯柔顺吸盘与实体 V 型托架通过密封、持续接触、分段双臂 IK
   和落位确认，覆盖单平行夹爪长度范围外的刚性长箱。

## 分类与应用边界

当前项目已经有基于 shape、尺寸、质量和 handling class 的可审计快递路由，可输出 carton、
mailer、fragile、oversize 和 cylindrical 目的地，并把分类结果写入语言任务。它是确定性语义
路由，不应写成“视觉模型自主识别全部快递类别”。当前冻结 VLA 结果覆盖 small carton、flat
mailer、electronics box 和 medium carton；21 类 catalog 是能力目录，不等于 21 类全部完成。

## 威胁与局限

- PASH-v25 是单个确定性长箱案例，不能用于成功率或泛化显著性。
- 96/100 只覆盖四类已知刚性 profile 的参数变化，不是未见几何体泛化。
- Force-Memory 是 Harness 侧接触历史，不是基础 VLM 内部学到的力 token。
- 自我改进发生在 episode 之间，不是执行中在线更新权重。
- 当前没有真机、软包裹、视觉分类精度或 Sim-to-Real 证据。
- 单 GPU 训练和推理已经证明，但上游 ROCm PR 尚未完成，不能声明社区贡献得分。
