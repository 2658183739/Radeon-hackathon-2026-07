# 接触分支诊断协议

## 目的

质量感知 30 mm 包裹适配器保留了已知 `+40 mm` 恢复，却把已知成功的 `+45 mm` 哨兵变成两次
完全一致的 38.3364 N 中止。聚合轨迹显示控制帧 202 到 203 之间从双侧 8 个接触点跳变到单侧
19 个接触点，但没有说明具体碰撞几何或手指执行器状态。

本协议在采集缺失的高频信号前冻结。它是机理诊断，不是性能、鲁棒性或模型选择实验；不得打开
评分器 holdout 或新 episode。

## 固定对照

| 字段 | 冻结值 |
|---|---|
| Profile / episode | `medium_carton / 4120001` |
| 候选 | `canonical-long-+0.000-up-0.045` |
| 仿真器 | Genesis 1.2.3 |
| 加速器 | 单张 Radeon `gfx1100`，ROCm 7.2 |
| 控制器 | 未修改的正式闭环运输 |
| 适配器几何 | 每指 30 mm |
| 有效密度 | 1240 kg/m3 |
| 安全中止 | 未修改的实测 35 N |
| 条件 A | 适配器碰撞几何 + stock 显式手指惯量 |
| 条件 B | 相同几何 + 合并质量、质心和完整惯量 |
| 高频窗口 | 控制帧 196--204（含），每帧全部 8 个物理子步 |
| 执行次数 | 每个条件一个全新场景执行 |

物理模型消融必须在配置和遥测中显式记录。条件 A 不是可部署的物理声明，只用于在当前代码中复现
早期轻量几何近似。

## 信号

冻结窗口内每个 240 Hz 物理子步记录：

- 命令、运输阶段、末端位姿和包裹位姿；
- 所有活动机器人接触，包括实体、全局 geom/link ID、link 名称、适配器/stock 几何标签、位置、
  法向、穿透深度和作用于两侧的力；
- 两根手指 DOF 位置和速度；
- 两根手指实际内部力与位置控制器力；
- 接触点数、峰值力、双侧包裹支撑和 35 N 越界。

紧凑结果必须报告条件首次分叉、首次失去双侧支撑、首次超过 35 N、峰值力接触身份，以及每根手指
实际力/控制力的最大绝对值。原始输出继续由 Git 忽略，但必须用字节数与 SHA-256 绑定。

跨条件分叉阈值冻结为：接触身份或双侧状态发生精确变化、包裹接触力或手指力相差 1 N、手指位置
相差 0.1 mm、手指速度相差 0.01 m/s。这些阈值只描述轨迹，不触发控制动作。

## 决策树

1. 若峰值来自适配器与包裹，另行冻结接触离散、碰撞边缘几何和柔顺性调查。
2. 若来自机器人与料箱、地面或自碰撞，给规划器加入带载 swept 路径间隙；不得调抓取高度。
3. 若接触身份不变但手指实际力/控制力分叉，测试有界轨迹调制或阻抗候选；不得增加夹力或削弱监督器。
4. 若没有信号能解释分支，把两种结果保留为仿真器接触敏感性基准，不启动多 profile 活动。

不得围绕该已观察哨兵扫描密度、延长量、摩擦、控制增益、力阈值或候选。任何后续干预都必须先有
新的预注册机理门，才能进入扩大评估。

## 文献依据

- *Contact Models in Robotics: A Comparative Analysis*（T-RO 2024，
  DOI `10.1109/TRO.2024.3434208`）支持把接触模型敏感性作为实验变量，而不是隐藏的仿真细节。
- *Reactive Diffusion Policy*（RSS 2025，DOI `10.15607/RSS.2025.XXI.052`）采用慢视觉策略与快速
  触觉反应处理接触丰富任务；它应当放在可信高频信号之后。
- *Bioinspired trajectory modulation for effective slip control in robot manipulation*（Nature Machine
  Intelligence 2025，DOI `10.1038/s42256-025-01062-2`）把轨迹适配作为增加夹力之外的方案，
  与本项目保持独立力边界的要求一致。
- *Diffusion Suction Grasping with Large-Scale Parcel Dataset*（IROS 2025，
  DOI `10.1109/IROS60139.2025.11246892`）与后续包裹几何覆盖直接相关，但吸盘属于另一种末端执行器，
  不能解释当前平行夹爪接触分支。
