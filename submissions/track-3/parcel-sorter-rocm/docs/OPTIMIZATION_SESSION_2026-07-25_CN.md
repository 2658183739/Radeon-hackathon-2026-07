## 目的与工程规范

本文记录一次优化会话中可复现的推理依据。流程遵循当前机器人与机器学习工程的常用
规范：冻结 episode 和安全阈值、先看遥测、一次只改一个主要变量、先测代码契约再跑
仿真、保留负结果、执行跨类别回归，并严格区分诊断烟雾与统计能力结论。

本文记录证据、备选方案、决策与实现技巧。单个确定性 episode 不会被写成成功率。

## 逐步决策记录

### 1. 修改控制前先审计失败

**观察：**横向圆筒使用 `dimensions[1] / 2` 作为半径，却用独立采样的
`dimensions[2] / 2` 作为生成高度。固定样本因此在台面上方约 5 mm 出生，机械臂接近前
先发生下落。

**备选：**围绕运动调整接近控制、增加导轨，或者先修复不一致的基本体。

**决策与原因：**先修基本体。不能让控制器适应几何生成错误。

**代码能力：**采样时把圆筒尺寸规范化：横筒为 `(长度, 直径, 直径)`，直立圆筒为
`(直径, 直径, 高度)`。生成高度与 Genesis 构造圆筒使用同一个半径。契约测试同时检查
两种映射。

### 2. 修正夹爪与邮筒的朝向

**观察：**旧的横筒 yaw 使夹指方向与邮筒轴线垂直，夹爪沿错误接触几何推动物体。

**决策与原因：**令夹指长度方向平行邮筒轴线，使夹爪闭合方向跨过圆筒直径；同时利用
平行夹爪对称性，不突破现有手腕范围。

**证据：**修复几何后峰值为 72.92 N；修正轴向后降到 43.54 N。该诊断仍失败，但方向
修正明显改善了目标接触几何，因此保留。

### 3. 分离自由空间速度与最终接近速度

**观察：**全局 10 mm 最终接近仍越过 35 N。让所有动作变慢会增加回合耗时，却没有
针对接触阶段。

**决策与原因：**新增 profile 可选参数 `final_approach_step_m`。邮筒只在水平对齐后使用
5 mm，自由空间仍保留 40 mm 上限。

**证据：**同一回合以 34.26 N 通过接近安全门槛，随后在抬升中丢失抓取。瓶颈从接近
碰撞转移到夹持稳定性。

### 4. 抬升前要求稳定双指接触

**观察：**一次瞬时双指接触就足以进入抬升。

**决策与原因：**给监督状态机增加 `grasp_stability_steps`，先要求连续三帧接触。任意
空档都会清零计数，同时保留原有力中止。

**证据：**邮筒连续三帧确认后进入抬升，初始抬升帧仍有接触，但随后滑脱；第二次重试
达到 48.05 N。稳定接触改善了阶段正确性，但没有解决夹持保持。

### 5. 按 profile 限制抬升加速度

**观察：**40 mm 笛卡尔请求使末端快速上移后丢失接触。首次慢抬升比原轨迹多保持约
四帧间歇接触。

**决策与原因：**增加 profile 可选参数 `lift_step_m=0.01`。普通盒类不变，同时为易滑或
易损对象提供明确变量。

**证据：**诊断最终在恢复阶段以 35.12 N 失败。它单独不足以解决问题，但轨迹支持把它
保留为邮筒接触策略的一部分。

### 6. 建模可更换高摩擦指垫

**观察：**夹爪上移而邮筒留在台面，符合滑移特征。Genesis 支持运行时逐 link 设置摩擦，
Panda/刚体默认摩擦约为 1.0。

**备选：**增加法向力、使用定位夹具、增加凹形几何，或者先建模高摩擦指垫。

**决策与原因：**先测试 `finger_friction=2.0`，因为它改变接触材料但不放宽 35 N 安全线。
参数按 Genesis 的 `(0, 5]` 范围校验，并且只在 profile 请求时同时应用到两个指夹 link。

**证据：**峰值降到 15.62 N，三次尝试都进入抬升，但邮筒仍滑脱。材料模型改善的是安全
与重试质量，不是完整任务成功。

### 7. 闭合前让指垫对准圆筒中心

**观察：**通用圆筒闭合窗口为 35 mm。轨迹显示手掌在目标上方约 33 mm 时便开始闭合，
指垫夹在圆筒顶部而非中心线。

**决策与原因：**增加 profile 可选参数 `pregrasp_tolerance_m=0.01`，显式收紧几何闭合条件。
不采用闭合后继续下降，因为之前的落座实验已经证明该路径不安全。

**证据：**这是第一个真正把邮筒抬离台面的候选：圆筒中心从 30.9 mm 升到 66.4 mm，
双指接触持续约 75 帧。邮筒之后仍滑落，因此只能算局部能力改善，不能算成功回合。

### 8. 拒绝更高夹持力候选

**观察：**中心对齐后，瓶颈由获取变成保持。

**备选：**保持 20 N、测试 25 N，或在实测安全线不变的情况下测试 35 N 命令边界。

**证据：**25 N 候选最高到 69.2 mm，随后实测 36.46 N；35 N 候选最高到 69.9 mm，
实测 35.19 N。两者都没有完成抬升。

**决策与原因：**拒绝两者，并从正式代码删除 profile 夹持力字段。3.5 mm 的局部增益不足
以证明越过固定安全线和扩大公开配置面的合理性。

### 9. 完整目录回归后拒绝全局稳定等待

**观察：**第一次 12 类完整回归从冻结的 8/12 诊断结果降到 5/12；`flat_mailer`、
`book_box` 和 `near_limit_box` 新增失败，而邮筒几何与材料参数本来都只作用于邮筒。

**根因：**`grasp_stability_steps=3` 被放在全局 task 配置中。

**决策与原因：**全局恢复为 1，并增加 profile 覆盖，只让两个邮筒 profile 使用 3。这复用
了滚动/扭转摩擦已经验证过的“缩小作用域”模式。

**验证：**最终仿真前，Radeon 上 67 项测试通过。限定作用域后的完整目录回归恢复到
8/12，逐 profile 完成结果与冻结对照一致。这是回归门槛，不是成功率估计。

## 最终保留的实现

| 能力 | 保留行为 | 保留原因 |
| --- | --- | --- |
| 基本体正确性 | 圆筒共享直径，并从同一半径计算生成高度 | 修复无效初始物理 |
| 几何感知抓取 | 横筒夹指平行于邮筒轴线 | 降低力并形成正确闭合几何 |
| 接触阶段动作 | 邮筒最终接近 5 mm、抬升请求 10 mm | 只在困难阶段减速 |
| 接触确认 | 邮筒要求连续三帧双指接触 | 排除瞬时接触且不让盒类退化 |
| 材料模型 | 邮筒 profile 的指垫摩擦为 2.0 | 降低峰值力并改善重试质量 |
| 位姿精度 | 邮筒闭合容差 10 mm | 首次实现真正离台 |
| 安全 | 实测 35 N 中止阈值不变 | 防止用重定义成功来“优化”结果 |

## 被拒绝的实现

| 候选 | 拒绝原因 |
| --- | --- |
| 双导轨原型 | 固定诊断中没有可测变化 |
| 25 N/35 N profile 夹持力 | 高度增益很小且越过安全线 |
| 全局三帧稳定等待 | 完整目录从 8/12 退化到 5/12 |
| 宣称邮筒成功 | 没有回合完成搬运与投放 |

## 复现阶梯

在已准备好的 Radeon 项目目录中执行：

```bash
source /workspace/rdna/bin/activate
export PYTHONPATH=src

python -m unittest discover -s tests -v

python scripts/evaluate_catalog.py \
  --config configs/catalog_v2.toml \
  --episodes-per-profile 1 \
  --profile mailing_tube \
  --output outputs/tube-diagnostic

python scripts/evaluate_catalog.py \
  --config configs/catalog_v2.toml \
  --episodes-per-profile 1 \
  --output outputs/catalog-regression
```

正式结果必须把单案例烟雾替换为预先声明的多回合保留集，并随报告保存配置、episode ID、
环境版本、原始 JSON 和 SHA-256。
