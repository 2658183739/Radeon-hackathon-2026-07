# 前沿方案执行决策：先几何闭环，再训练学习模型

状态日期：2026-07-26。本文件是执行记录，不是能力声明。它把当前证据、近期
开源机器人方案和单张 Radeon 约束转换成分阶段实验计划。冻结协议产出结果前，
所有效果都仍是未知的。

## 1. 当前证据边界

本地源码通过 323 项确定性测试，另有 1 项可选测试跳过。128 个圆柱样本的候选
总体审计已通过，但该审计没有创建场景，也没有读取任务结果；它只证明候选生成
稳定且覆盖预定几何，不能证明 IK 可达、抓取稳定或分拣成功。24 样本 ROCm
IK/FK/网格碰撞静态筛查已经冻结，必须等待 V5 控制器探针释放唯一一张 Radeon。

V5 是针对刚性箱体动态安全否决器的独立确认。冻结 runner 生成最终结果文件前，
不得利用部分候选结果。即使 V5 通过，也只允许继续做在线并行探针实验，不能直接
把否决器接入默认控制器。

## 2. 前沿方案决策

| 候选方案 | 实际提供的能力 | 单 Radeon 决策 |
| --- | --- | --- |
| 几何感知候选规划 | 可解释的 IK、FK、碰撞、可操作度和 retry 决策 | 论文主方法，先补齐静态与闭环证据 |
| RGB-D 解析几何 | 可量化误差的形状、位姿和尺寸估计 | 规划器在特权几何下有效后，优先实现的感知方法 |
| ACT RGB/RGB-D | 已通过 LeRobot 接入的低数据动作分块基线 | 均衡数据门禁通过后的正式学习基线 |
| 紧凑 Diffusion Policy | 表达多峰动作，但推理开销更高 | ACT 后做匹配比较；固定 checkpoint 后再比较去噪步数 |
| VLA-Adapter 0.5B | 小型语言条件策略实现，不是快递任务 checkpoint | 首选 VLA 兼容性实验；许可证与 ROCm 审计后才做 LoRA/动作头微调 |
| OpenVLA-OFT 7B | 连续动作分块和较强参考实现 | 初期只作参考；上游称推理约需 16-18 GB，且技术栈偏 CUDA |
| VLA evaluation harness | 模型服务与仿真基准解耦、分片评测 | 借鉴协议；它不是模型、不含本 Genesis 任务，公开容器也基于 CUDA |
| 力历史 VLA 思路 | 视觉无法区分接触状态时利用力历史 | 先实现为候选选择器的小型力 token，不先替换整个 VLA |
| 学习型世界模型 | 长时域预测的隐变量或视频动力学 | 刚体几何与闭环控制不再是主误差后再做 |
| ROS 2 / MoveIt 2 | 部署、录包回放和真实机器人接口 | 算法冻结后接入，不能把中间件包装成核心创新 |

35 N 硬安全监督、几何能力门禁和末端执行器契约始终置于学习模型之外。语言模型
可以选择任务或候选族，但不能绕过 IK、碰撞、力和夹爪开口检查。

## 3. 多形状快递总体

当前 catalog 已包含 12 个平行夹爪训练分层：10 个箱体分层，范围从
60 x 35 x 25 mm 微型盒到 420 x 79 x 180 mm 大型窄纸箱；1 个直立罐筒
分层，直径 40-70 mm、高度 60-160 mm；1 个卧式快递筒分层，长度
150-300 mm、直径 35-65 mm。质量、摩擦、yaw、动作延迟和观测噪声在已提交
范围内独立随机化。

官方承运商尺寸，以及更大的长方体、正方体、信封和筒体，保留为只评测的能力
边界。它们的短轴超过 Panda 平行夹爪开口，或明确需要吸盘/承托器。系统需要
渲染这些对象并给出明确拒绝原因，不能把它们混入平行夹爪失败率，也不能虚报为
可抓取。

该划分分别回答两个问题：当前硬件能否稳定分拣物理能力范围内的多类快递；系统
能否识别能力范围之外的物体，并把它路由给其他末端执行器。

## 4. 冻结执行顺序

### 阶段 A：机理证明

1. 完成 V5，并严格按预注册门禁判定，不读取部分候选结果。
2. 运行 24 样本圆柱 ROCm 静态筛查。通过条件包括：每个圆柱 profile 至少
   75% 样本存在可行候选，状态恢复误差不超过 `1e-7`，只有一张 HIP 设备，
   筛查计算 P95 小于 5 秒。
3. 若静态筛查通过，在隔离配置中接入圆柱候选选择；若失败，只能在新的开发协议
   中修改候选，并完整保留失败结果。
4. 修改默认控制器前，先做小规模匹配圆柱闭环筛选。静态可行不能直接证明闭环成功。

### 阶段 B：论文主方法

对同一组物理样本比较三条路径：历史控制器、碰撞检查复位、碰撞检查复位加多形状
可行位姿规划。

现有 12 profile、每 profile 5 个 episode 的实验仍只是淘汰筛选。正式确认阶段
为每个受支持 profile 冻结 30 个未见物理 episode，即每个实验臂 360 个配对
单位，避免一类困难纸箱决定整篇论文。成功率是主指标；力中止和掉落是安全共同
指标；峰值力、时长、规划延迟和吞吐量是次指标。

只有当总体成功提升、力中止和掉落不恶化、不同形状分层方向一致，且简单 profile
没有实质回归时，主方法才晋级。报告 Wilson 区间、精确配对 McNemar 检验、配对
bootstrap 效应量和 profile 分层结果。

### 阶段 C：消融与鲁棒性

每项消融都从最终方法中只移除一个机制：碰撞过滤、可操作度排序、对称腕部候选、
retry 重新规划，以及只有 V5 和在线实验都通过后才加入的动态安全探针。

所有消融使用同一 episode manifest，并用 Holm 方法校正确认性假设族。鲁棒性实验
分别改变未见尺寸、质量、摩擦、yaw、相机噪声、动作延迟和轻微外部扰动。除非
明确标记为组合压力测试，不在一个 cell 同时改变多个因素。

### 阶段 D：视觉感知

在相同闭环 episode 上比较特权几何、加噪特权几何和 ROCm RGB-D 几何。第一版
感知前端采用解析方案：

```text
米制深度 -> ROCm 反投影 -> 去除桌面 -> 快递点云
         -> 有向包围盒/圆柱拟合 -> 置信度
         -> 不变的候选规划器和安全监督器
```

先报告位置、姿态、尺寸和形状误差，再报告任务成功率。只有解析误差呈稳定系统性，
且有足够未见数据可以检验修正时，才训练小型残差头。

### 阶段 E：学习策略

至少获得 300 条均衡成功 RGB-D 回合，并冻结按物理 episode 和 profile 分组的
train/development/holdout 划分后，才开始正式训练。先在同一划分上训练三种子
ACT RGB 与 ACT RGB-D，再训练紧凑 Diffusion RGB-D。checkpoint 按开发集闭环
成功率选择，不能按离线 loss 选择；每个已选择种子至少评测 60 个固定 holdout
episode。

VLA-Adapter 只有在隔离 ROCm smoke 验证全部算子、记录基础模型/checkpoint/依赖
许可证，并证明动作/状态适配无损后才进入。首轮采用 LoRA 或动作专家、梯度累积、
AMP 和单一任务指令。它必须和 ACT 使用相同数据及安全监督，不能拿 LIBERO 预训练
checkpoint 与快递专用策略直接比较后声称数据等价。

## 5. AMD GPU 优化顺序

每个被接受的模型采用相同优化阶梯：eager FP32 正确性基准；AMP 且检查数值和
任务结果不变；在 48 GB 显存上做 batch/梯度累积扫描；同步测量预热后 P50/P95
延迟和峰值显存；只有 ROCm 支持已验证且 fallback 被记录时才尝试
`torch.compile` 或融合算子；只有确定性状态等价通过后才做环境分片或 scene clone。

优化目标是端到端任务时间，而不是单个 kernel 吞吐。分别报告场景构建、首次编译、
感知、规划、推理、物理、渲染和清理耗时。任何以成功率下降或削弱 35 N 边界为
代价的加速都必须拒绝。

## 6. 停止规则与论文就绪定义

只有以下证据全部存在，才称为论文就绪：未见配对 episode 上的正向多 profile 主
比较；完整机理消融和失败分类；至少一项移除特权快递位姿的感知对照；三种子
ACT RGB/RGB-D 和一个匹配的随机策略结果（或明确失败的数据门禁）；ROCm 性能
证据；不可变配置、manifest、原始 summary、artifact 哈希和中英双语记录；以及
纯仿真、夹爪开口、刚性信封近似和缺少真实机器人验证等限制。

若最终规划器在未见闭环数据上没有提升，停止正向方法论文。备选路线是扩大“安全
干预负结果与失败机理”基准；已经用于开发的 episode 不能重新包装成确认数据。
