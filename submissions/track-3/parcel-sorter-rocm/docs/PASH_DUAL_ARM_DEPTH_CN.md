# PASH 双臂几何 Harness

## 范围

本扩展让冻结的 RGB SmolVLA 只在快递运输阶段，对左右机械臂的位置拥有受限控制权。模型不会在任务执行中在线更新权重；工具开合、末端姿态、抓取、抬升、放置、释放以及 35 N 硬安全线仍由确定性控制器负责。

设计吸收了两类公开工作的系统思想：

- 参考 Harness VLA，把 VLA 封装成受限动作原语，由规划器、确定性原语和安全门决定何时调用；
- 参考 InSight 的 primitive gap 思路，把成功恢复记录为技能回写候选，但必须先通过 RGB-D 与动作数据审计，才能进入离线再训练。

Harness VLA 的主来源为[项目主页](https://harnessvla.github.io/)和
[arXiv:2607.08448](https://arxiv.org/abs/2607.08448)。InSight 当前只作为设计参考；正式论文提交前必须补齐并核验其原始论文元数据，不能引用二手文章代替论文。

## 关键决策与原因

1. **保留 RGB SmolVLA。** 已完成的配对实验中，RGB-D 检查点虽然可以运行，但动作 MAE 和延迟均退化，因此不直接启用。
2. **把深度作为确定性几何侧路。** 中央区域的米制深度用于计算传感质量与近相机遮挡缩放上限。深度缺失、格式错误或大面积无效时，系统关闭学习式权限并回退专家。该侧路不是机械臂与障碍物距离估计器。
3. **先投影双臂提议，再进行 IK。** 左右臂残差分解为共同运动和差分运动。共同运动最大 10 mm；独立搬运时差分最大 1.5 mm；三吸盘和 V 型托架共同承载刚性纸箱时，差分强制为零。
4. **接近放置点时逐渐撤权。** 剩余距离大于 120 mm 时可以使用完整受限权限，25 mm 时降为零；放置和释放阶段不允许学习式机械臂残差。
5. **双臂联合求解。** 左右目标通过同一次多末端 IK 验证；IK 失败或出现非有限值时丢弃该次更新。
6. **接入回合级策略记忆。** 协同托举任务可选择 `pash_dual_arm`；如果发生 35 N 事件，下一次只允许专家恢复；吸附、抬升、放置或释放失败会撤掉下一次的学习式机械臂权限。

## 单 Radeon 机理结果

实测环境为单张 `gfx1100` Radeon、ROCm 7.2.1、PyTorch 2.9.1 ROCm、Genesis 1.2.3，以及冻结的 2,400 步 RGB SmolVLA v2。任务对象为固定的 `1.44 x 0.12 x 0.18 m`、0.40 kg 刚性超长纸箱。

| 指标 | 结果 |
| --- | ---: |
| 完整任务 | 通过 |
| 抬升高度 | 8.53 cm |
| 运输距离 | 30 cm |
| 最终放置误差 | 3.19 cm |
| 断吸次数 | 0 |
| 最大吸力 / 吸盘接触力 | 27.03 / 14.90 N |
| V 型托架最大接触力 | 30.68 N |
| VLA 推理 | 67 次，3 Hz |
| 热启动平均 / P95 延迟 | 203.22 / 210.52 ms |
| 双臂 IK 接受次数 | 24 |
| 左 / 右臂非零更新 | 24 / 24 |
| 双臂残差实际物理步 | 2,356 |
| 最大工具间距变化 | 0 m |
| Force Memory 收紧次数 | 11 |
| 深度失效关闭次数 | 0 |
| 紧急停止 | 0 |

本场景的深度图有效且没有近相机遮挡，因此深度缩放上限保持为 `1.0`。这表示侧路正确地没有误干预，不代表深度门无用；缺失深度和近裁剪面遮挡已经由单元测试覆盖。

## 复现命令

命令与参数见英文版 [PASH_DUAL_ARM_DEPTH.md](PASH_DUAL_ARM_DEPTH.md)。核心开关为：

```text
--policy-mode base_dual_arm_residual
--force-memory-harness
--depth-risk-sidecar
--cooperative-cradle
```

原始证据位于 `evidence/mobile_bimanual/dual_arm_depth_v1/`。

## 证据边界

这是一个确定性机理案例，只能证明双臂学习残差、深度侧路、Force Memory、多末端 IK、三吸盘和 V 型托架已经在单张 Radeon 上同时进入闭环，并且没有越过登记的安全门。它不能被写成成功率、未见几何泛化、重试收益、学习式视觉分类精度或 Sim-to-Real 结果。
