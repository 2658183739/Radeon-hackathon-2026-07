# 移动 SmolVLA 左臂残差消融

## 问题与范围

本实验检验：在已经通过冻结评测的 SmolVLA v2 底盘残差控制上，是否可以让同一模型在运输阶段
实际控制左臂位置残差，而不降低任务成功、安全和放置精度。实验不重新训练模型，不改变吸盘、
姿态、抬升或释放控制，因此只归因于“锚定式运输左臂残差”这一项机制。

机器人为三自由度全向底盘加双七轴 Franka Panda。左臂使用三个实体柔顺吸盘，右臂 V 型托架
仍为被动结构。SmolVLA 以 3 Hz 运行，Genesis 物理和确定性安全控制器以 240 Hz 运行。所有
回合均在单张 AMD Radeon `gfx1100`、ROCm 7.2.1 上执行。

## 控制方法

基线使用 `base_residual`：SmolVLA 在抓取接近和运输阶段贡献有界底盘速度残差，机械臂由专家
控制。候选使用 `base_arm_residual`，保留相同底盘控制，并只在运输阶段加入左臂位置残差：

- 位置以“运输开始时末端相对底盘的专家锚点”为中心，累计残差限制为 1 cm；
- 姿态、吸盘命令、抓取、抬升、放置和释放继续由专家锁定；
- 每次 3 Hz 策略更新执行一次 Genesis IK；无穷值或 IK 失败立即回退专家关节目标；
- Harness-Lite 的 5 cm/s 底盘、4 cm 单步、1 cm 残差和 35 N 接触力边界保持不变。

因此候选证明的是 VLA 驱动的真实机械臂位置执行，不是完整双臂自主控制。

## 开发门禁

种子 `20260729` 在结果未知时生成 12 个参数回合，四类各 3 个。基线和候选均为 11/12；唯一
失败发生在运输前。候选在 11 个可运输回合全部执行左臂残差，270 次 IK 全部接受，0 次力越界。
平均成功放置误差从 1.37 cm 增到 2.31 cm，仍在预注册的 `+1 cm` 开发容差内，因此只授权新的
冻结留出集，不作泛化声明。

## 冻结 100 回合协议

开发结果冻结后，种子 `20260730` 生成新的 100 回合，`small_carton`、`flat_mailer`、
`electronics_box`、`medium_carton` 各 25 个。尺寸、质量、摩擦和 XY 偏移均随机化，episode ID
与开发集零重叠。基线和候选使用同一 checkpoint、参数顺序、3 Hz 策略和四个隔离 worker。

晋级要求同时满足：成功率至少 80%，相对基线 5 个百分点的点估计和 Wilson 下界非劣性，
零 35 N 越界，每个可运输候选回合实际执行机械臂残差，IK 有接受且零拒绝，全部回合记录单卡
Radeon/ROCm，以及候选平均成功放置误差不超过基线 1 cm。

## 结果

| 指标 | 底盘残差基线 | 底盘 + 左臂残差 |
| --- | ---: | ---: |
| 成功率 | 94/100 | 94/100 |
| Wilson 95% | 87.52%--97.22% | 87.52%--97.22% |
| 小纸箱 | 25/25 | 25/25 |
| 扁平件 | 20/25 | 20/25 |
| 电子盒 | 25/25 | 25/25 |
| 中型纸箱 | 24/25 | 24/25 |
| 平均成功放置误差 | 1.40 cm | 2.45 cm |
| 最大接触力 | 16.50 N | 16.73 N |
| 35 N 越界 | 0 | 0 |
| 实际左臂运输回合 | 0 | 94/94 |
| 左臂 IK 接受/拒绝 | 0/0 | 2306/0 |

配对结果为双方成功 94、双方失败 6、候选恢复 0、候选回归 0，精确 McNemar 双侧 `p=1.0`。
94 个共同成功回合中，候选放置误差平均增加 1.0527 cm，中位增加 1.0868 cm。成功率、Wilson、
安全、执行、IK 和单卡 ROCm 门均通过，但精度增量超过 1 cm 容差 0.0527 cm，因此自动状态为
`completed_not_promoted`。

## 决策与下一实验

正式控制器继续使用 SmolVLA v2 的 `base_residual`。本结果不能通过放宽 1 cm 门限“修成成功”；
候选没有恢复任何任务失败，却稳定增加放置误差，说明当前 checkpoint 的机械臂输出还不适合作为
运输位姿残差。下一次实验应重新采集带底盘运动和末端扰动恢复的运输片段，并对机械臂位置维度做
显式损失平衡；完成新的训练内离线消融后，再冻结全新参数集，不能复用本 100 回合调参。

本实验不支持右臂托架协作、未见几何体、完整动作 VLA、Sim-to-Real 或现实机械臂能力声明。
紧凑证据、冻结配置、运行状态和 SHA-256 位于
`evidence/mobile_bimanual/arm_residual_v1/`。
