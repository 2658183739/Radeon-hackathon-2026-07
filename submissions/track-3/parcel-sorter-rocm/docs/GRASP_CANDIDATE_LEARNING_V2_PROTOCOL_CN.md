# 几何作用域内抓取候选学习 V2 协议

## 动机

V1 把标签生成绑定到已观察的碰撞复位回退。12 个训练组只有 4 个生成标签，
6 个开发组只有 1 个生成标签，而且唯一开发组没有安全候选。V2 改变研究
总体，而不根据已观察标签挑样本：研究所有已经进入冻结几何规划作用域的
原装手爪包裹。碰撞检查复位继续作为安全机制启用，但不再决定是否生成候选
标签。

## 物理执行前选择 episode

纳入四个平行夹爪纸箱 profile：`medium_carton`、`shoe_box_proxy`、
`large_narrow_carton` 和 `near_limit_box`。其未使用 episode 命名空间分别从
`8410000`、`8510000`、`8710000` 和 `8810000` 开始。每个 profile 最多按
ID 升序检查 256 个确定性随机化输出，选择前 16 个满足既有方法谓词的样本：

```text
shape == box 且高度 >= 0.105 m 手掌间隙 + 0.020 m 侧面重叠
```

该步骤只读取随机化包裹参数，不得构建 Genesis 场景、查询碰撞、执行动作或
读取任务结果。每个 profile 前 8 个入训练集，随后 4 个入开发集，最后 4 个
入 holdout。选择器先输出带哈希审计，再把精确 ID 写入冻结 TOML 协议。

## 冻结采集

- 机器人：Genesis 1.2.3 原装 Panda 手爪，不使用生成适配器。
- 平台：单张 Radeon `gfx1100`、ROCm 7.2、240 Hz Genesis 物理。
- 控制器：生产专家、碰撞检查复位、单向运输契约、零重试、35 N 中止不变。
- 规划激活：所有满足既有几何谓词的样本。
- 唯一干预：在新场景中强制最多六个静态可行候选 ID 之一。
- 预算：32 个训练组、16 个开发组、16 个锁定 holdout 组；最多 384 次控制器
  保真 rollout。

训练必须先于开发完成。模型选择只能使用训练与开发数据。冻结唯一评分器及
全部超参数前，holdout 保持锁定。不满足几何作用域的输出属于可审计选择失败，
不得静默删除；至少 15/16 个开发组生成完整标签后，模型选择才有效。

## 模型与升级边界

静态排序继续作为基线。V2 至少比较原封不动的 6,276 参数 MLP 和一个使用
相同版本化特征的组内安全优先排序器。硬 IK、碰撞可行性和 35 N 监督器始终
位于所有学习模型之外。

打开 holdout 前，选定评分器必须相对静态排序减少开发集安全中止或恢复任务
成功，不得产生逐 profile 安全回归，并在 Radeon 上保持六候选预热 P95 小于
5 ms。holdout 只执行一次。结构化排序证明留出价值前，不扩展 ACT、Diffusion、
VLA、视觉嵌入或 ROS 2。

## 后续论文评测

候选标签 rollout 不是最终成功率样本。若 holdout 门禁通过，接入后的方法将
进入另行预注册的 200--500 episode 对比，覆盖普通纸箱、困难纸箱、圆柱体和
几何作用域外边界 profile，并报告配对任务、安全、延迟和 profile 分层统计。
